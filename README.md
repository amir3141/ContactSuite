# ContactSuite

A modern desktop contact management application developed with **Python**, **Tkinter**, and **SQLite**.

## ✨ Features

- Modern and responsive desktop interface
- Add, edit, and delete contacts
- Smart search across all contact fields
- SQLite database storage
- Export contacts to PDF
- Export contacts as vCard (.vcf)
- Generate QR codes for contact sharing
- JSON backup and restore
- Clean, modular project architecture

## 📦 Requirements

- Python 3.11 or later

Install dependencies:

```bash
pip install -r requirements.txt
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/amir3141/ContactSuite.git
```

Go to the project folder:

```bash
cd ContactSuite
```

Run the application:

```bash
python main.py
```
